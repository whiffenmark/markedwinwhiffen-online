# Mark Edwin Whiffen - Personal Website

A clean, modern, and mobile-friendly personal brand website for Mark Edwin Whiffen, licensed insurance agent and digital builder.

## Cloudflare Pages Deployment Settings

To deploy this website on Cloudflare Pages, use the following build configuration:

*   **Build command**: `exit 0`
*   **Output directory**: `/`

## Features
*   **Fully Responsive**: Optimised for both desktop and mobile devices.
*   **SEO & Open Graph Ready**: Custom meta titles, descriptions, and Open Graph tags included.
*   **Structured Schema**: Integrated JSON-LD `Person` schema for search engines.
*   **Clean Design**: Simple, readable layout with zero clutter.
*   **Medicare & Insurance Compliance**: Includes essential Medicare disclaimers and compliance notices.

## Project Structure
*   `index.html` - Primary HTML structure.
*   `styles.css` - Custom vanilla CSS.
*   `assets/images/profile.jpg` - Profile photo.
